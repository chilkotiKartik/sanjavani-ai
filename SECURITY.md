# Security & Responsible Disclosure Policy

Sanjeevani is designed for critical medical triage and emergency navigation. We take security, patient data privacy, and secret protection with the utmost seriousness.

---

## 🛡️ Supported Versions

| Version | Supported |
|---|---|
| `1.0.x` (main) | ✅ Yes |

---

## 🔒 Reporting a Vulnerability

If you discover a security vulnerability or secret leakage risk in Sanjeevani, please report it privately:

- **Email**: `chilkotikartik@gmail.com`
- Please include:
  1. Description of the issue.
  2. Proof of concept or reproduction steps.
  3. Potential impact.

We will acknowledge receipt within **24 hours** and provide a patch and disclosure timeline. Please do **not** file public issues for active security vulnerabilities.
